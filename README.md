## プロジェクト

### Scouting App · 選手探索・比較ツール

**個人開発 / 非公開**

同じポジションでも、チームが選手に求める仕事は違います。ポジション名で検索したあと、欲しいプレーをする候補を比較できるように、選手検索・スクリーニング用のWebアプリを開発しました。

- **選手像を検索条件にする** — ポジションごとに求めるプレーを整理し、候補を探すための指標に落とし込みました。
- **比較の前提を揃える** — シーズンや出場時間を指定して候補を比較できるようにし、データ不足で評価できない項目は判別できるようにしました。
- **次に見るべきプレーを絞る** — たとえば、サイドから内側に入ってシュートを狙える候補を探すときは、シュート傾向を手がかりに候補を抽出します。受ける位置や内側へ運ぶ動きは、映像で確認する前提です。

### チームパフォーマンス分析

得点・失点と、xG（得点期待値）・xGA（失点期待値）、ペナルティーエリアへの侵入を比較するレポートを作成しました。実際の得失点とチャンスの傾向を並べ、リーグ内での位置づけや、映像で掘り下げるべき点を整理しました。
